# Core Python Interview Questions (Set 1)

## 1. What is Python?
Python is a high-level, interpreted programming language known for readability and simplicity. It supports multiple paradigms like procedural, object-oriented, and functional programming.

---

## 2. What are Python's key features?
- Easy syntax and readability  
- Dynamic typing  
- Automatic memory management  
- Large standard library  
- Cross-platform support  

---

## 3. What are mutable vs immutable data types?
- Mutable: Objects can be changed (list, dict, set)  
- Immutable: Cannot be changed after creation (int, float, str, tuple)

---

## 4. What is the difference between `is` and `==`?
- `==` checks value equality  
- `is` checks object identity (same memory reference)

---

## 5. What is a list vs tuple?
- List: Mutable, slower, uses more memory  
- Tuple: Immutable, faster, memory efficient  

---

## 6. What is a dictionary in Python?
A collection of key-value pairs where keys must be immutable and unique. It provides fast lookup using hashing.

---

## 7. What is a lambda function?
A small anonymous function defined using `lambda`, used for short, one-line operations.

---

## 8. What are *args and **kwargs?
- `*args`: Accepts variable number of positional arguments  
- `**kwargs`: Accepts variable number of keyword arguments  

---

## 9. What is a generator?
A function that uses `yield` to return values one at a time, saving memory by lazy evaluation.

---

## 10. What is the difference between shallow copy and deep copy?
- Shallow copy: Copies references of objects  
- Deep copy: Creates completely independent copies of objects  

---
